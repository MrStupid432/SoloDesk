SOLODESK — FIRST WEBSITE FILES

WHAT THIS IS
A small, mobile-friendly prototype for organising jobs, tasks and completed-job income.

FILES
- index.html: page structure
- style.css: appearance and responsive layout
- app.js: app behaviour and browser storage

HOW TO TEST ON YOUR DEVICE
1. Upload all three files to a GitHub repository.
2. Open the published GitHub Pages address in your phone browser.
3. Add a test job and a test task.
4. Refresh the page. The demo data should remain in that same browser on that same device.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub (ask a parent/guardian to help with account setup if needed).
2. Create a NEW PUBLIC repository named solodesk.
3. Upload index.html, style.css, app.js and this README.txt to the repository's top level.
4. Open the repository's Settings.
5. Choose Pages in the left-side menu.
6. Under "Build and deployment", choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.
8. Wait a few minutes and refresh the Pages screen. Open the website address shown there.

IMPORTANT LIMITATIONS
- This is a prototype, not a secure multi-user product.
- Data is saved in browser localStorage. It does not sync between devices or users.
- Do not enter real customer contact details, payment details, passwords or sensitive information.
- A public repository makes the source code public. Never upload secrets, API keys or private customer data.
- Before accepting paying customers, add proper authentication, secure cloud storage, privacy terms, backups and appropriate adult/business oversight.
